# Mudabbr Application System

## Project Overview

**Mudabbr** is an intelligent expense management Android application designed to help users track their income, expenses, bills, and spending habits efficiently.

The application uses **OCR technology** to scan receipts and automatically extract expense information, while providing budgeting, reports, reminders, and spending predictions.

## Project Objectives

The system was designed to:

* Automate receipt scanning and expense data entry
* Organize expenses into categories
* Provide daily, weekly, monthly, and yearly expense reports
* Predict future spending patterns
* Send budget and bill due-date notifications
* Improve financial planning and spending awareness
* Provide secure authentication using passwords and biometrics

## System Implementation

The application includes several modules:

### User Management

* User registration and login
* Password recovery and reset
* Profile management
* Fingerprint authentication
* Secure logout

### Expense Management

* Add, update, view, and delete expenses
* Scan receipts using **OCR**
* Automatically add extracted receipt values to expenses
* View expense details and current monthly spending
* Receive alerts when expenses exceed the budget

### Income Management

* Add, update, view, and delete income records
* Manage income data within the application

### Bill Management

* Add, update, view, and delete bills
* Track bill due dates
* Receive bill payment reminders

### Reports & Prediction

* Daily, weekly, monthly, and yearly expense reports
* Expense analysis by category
* Monthly spending analysis
* Predicted expenses based on spending patterns

### Admin Module

* View registered users
* View user details
* Manage and delete users

## System Validation

The system was tested through:

* **Unit Testing** – individual system functions such as login, expense management, bill management, OCR receipt scanning, and predictions
* **Integration Testing** – testing complete workflows between connected modules
* **Acceptance Testing** – validating security, availability, usability, performance, and reliability requirements

All implemented test cases passed successfully.
